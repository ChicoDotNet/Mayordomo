# Support

Mayordomo Engine is currently pre-alpha.

Use GitHub issues for reproducible public-safe defects and proposals involving engine behavior, deterministic replay, simulations, tooling, CI, documentation, build behavior, and public contracts.

Do not use public issues for:

- weaponizable security details;
- secrets or credentials;
- private `Mayordomo.Game` code;
- official/private cards or branded assets;
- licensed text/content that cannot be redistributed;
- personal player/customer data;
- sensitive Code of Conduct reports.

There is currently no production support SLA, compatibility guarantee, store-publishing commitment, or commercial-service commitment associated with this repository.
