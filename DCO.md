# Developer Certificate of Origin

Mayordomo Engine uses the **Developer Certificate of Origin (DCO) 1.1** sign-off model.

Canonical DCO: https://developercertificate.org/

Add the following trailer to contributed commits:

```text
Signed-off-by: Your Name <you@example.com>
```

Git can add it automatically with:

```bash
git commit -s
```

By signing off, you certify that you have the right to submit the contribution and that it may be distributed under this repository's MIT License.

The sign-off does not transfer copyright to the founding maintainer.
