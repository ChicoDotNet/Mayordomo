# Security Policy

Mayordomo Engine is currently pre-alpha and has no supported production release.

## Report privately

Use a private reporting path for findings that could enable:

- arbitrary code execution;
- credential/token exposure;
- dependency or artifact substitution;
- authorization bypass;
- cross-match/player isolation bypass;
- unauthorized authoritative-state mutation;
- RNG/replay tampering that changes authoritative outcomes;
- hidden-information disclosure;
- supply-chain compromise.

Prefer GitHub private vulnerability reporting when available.

Do not publish weaponizable details, secrets, proprietary game material, or personal data before maintainers can investigate.

Ordinary non-sensitive bugs belong in normal issues.

## Supported versions

There are currently no supported release versions. Security fixes apply to the active development line as appropriate.
